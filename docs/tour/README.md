# The 90-second tour, as a terminal session

Sample data: generated by scripts/gen_corpus.py, not real research. No customer content appears here, and no workspace you care about is
touched: every command carries `--db`, and the export writes into a temporary directory.

Generated by `scripts/tour.py` from [`script.md`](script.md): every command below was
run, in order, against a throwaway store, and its real output is what the cast shows.
Do not hand-edit this file or `tour.cast` — change the script and regenerate:

```bash
uv run python scripts/tour.py --write
```

## Play it

```bash
asciinema play docs/tour/tour.cast
```

The recording runs **54.20 seconds** against a budget of
90 seconds. Its pace comes from the pinned timings in
`scripts/tour.py`, not from the wall clock, so it is the same length on every machine.

## What happens, in order

1. **Load the demo study** — `uv run python scripts/gen_corpus.py --out "$TOUR_DB" --outcomes 48 --jobs 2`
2. **Confirm the store is reachable** — `uv run agentic-odi --no-update --db "$TOUR_DB" health`
3. **See what is in it** — `uv run agentic-odi --no-update --db "$TOUR_DB" jobs list`
4. **Read the job the way the method reads it** — `uv run agentic-odi --no-update --db "$TOUR_DB" summary JOB-0000`
5. **The map itself, in order** — `uv run agentic-odi --no-update --db "$TOUR_DB" steps list --job-id JOB-0000`
6. **The outcomes behind one phase** — `uv run agentic-odi --no-update --db "$TOUR_DB" desired-outcomes list --job-id JOB-0000 --step-id STP-0000-2`
7. **Check the arithmetic yourself** — `uv run agentic-odi --no-update --db "$TOUR_DB" score 8 3`
8. **Follow a claim back to its evidence** — `uv run agentic-odi --no-update --db "$TOUR_DB" evidence list --outcome-id OUT-00016`
9. **Group the need, not the demographic** — `uv run agentic-odi --no-update --db "$TOUR_DB" segments run --job JOB-0000`
10. **Ask what the evidence supports** — `uv run agentic-odi --no-update --db "$TOUR_DB" strategy propose --job JOB-0000`
11. **Read the recommendation again later** — `uv run agentic-odi --no-update --db "$TOUR_DB" strategy show`
12. **Take it with you** — `uv run agentic-odi --no-update --db "$TOUR_DB" data-export --output "$TOUR_OUT/study.json"`

## Type it yourself

Set up the disposable workspace first, then run the steps in order — the same tour
without a recording.

```bash
export TOUR_WORKSPACE="$(mktemp -d)/tour"
export TOUR_DB="$TOUR_WORKSPACE/tour.db"
export TOUR_OUT="$TOUR_WORKSPACE/out"
mkdir -p "$TOUR_OUT"
```

```text
uv run python scripts/gen_corpus.py --out "$TOUR_DB" --outcomes 48 --jobs 2
uv run agentic-odi --no-update --db "$TOUR_DB" health
uv run agentic-odi --no-update --db "$TOUR_DB" jobs list
uv run agentic-odi --no-update --db "$TOUR_DB" summary JOB-0000
uv run agentic-odi --no-update --db "$TOUR_DB" steps list --job-id JOB-0000
uv run agentic-odi --no-update --db "$TOUR_DB" desired-outcomes list --job-id JOB-0000 --step-id STP-0000-2
uv run agentic-odi --no-update --db "$TOUR_DB" score 8 3
uv run agentic-odi --no-update --db "$TOUR_DB" evidence list --outcome-id OUT-00016
uv run agentic-odi --no-update --db "$TOUR_DB" segments run --job JOB-0000
uv run agentic-odi --no-update --db "$TOUR_DB" strategy propose --job JOB-0000
uv run agentic-odi --no-update --db "$TOUR_DB" strategy show
uv run agentic-odi --no-update --db "$TOUR_DB" data-export --output "$TOUR_OUT/study.json"
```

The store comes from `scripts/gen_corpus.py`, which is deterministic: the job is always
`JOB-0000`, and every id in the tour resolves the same way on your machine.

## Where the terminal stops

The tour ends at the exported study because that is where the terminal ends. The
decision brief is rendered in the browser (`apps/studio/src/lib/brief.ts`), so it is
not in the terminal and does not appear in this recording; the annotated screenshots
of it belong to ALH-236. The same loop as a conversation is
[The Living Studio](../living-studio.md), and the reasoning behind every command is in
the numbered steps of [`script.md`](script.md).
