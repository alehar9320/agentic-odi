# Studio E2E Testing — Implementation Plan

**Date:** 2026-10-22
**Branch:** `feat/e2e-playwright`
**Spec:** `docs/superpowers/specs/2026-10-22-studio-e2e-testing-design.md`

## Goal

Ship a browser-level E2E suite for the Living Studio, plus the two MCP
passthrough fixes the suite exposed, plus a CI step that can be disabled
without a code change.

## Preconditions

- Worktree `.worktrees/e2e-playwright` created from `origin/main` (624b6857).
- `uv sync --all-packages --locked` completed in the worktree.
- `npm ci` in `apps/studio` completed.

## Tasks

### Task 1 — Fix the MCP result parsing (Fix A)

**File:** `apps/studio-api/src/agentic_odi_studio_api/studio/mcp_data.py`

Add a module-level helper that extracts the text payload from a FastMCP tool
result, mirroring `_content_text` in
`packages/connectors/src/agentic_odi_connectors/mcp/connector.py`.

Use it in three places in `fetch_canvas` (`get_jobs`, `get_job_map`,
`get_outcomes`) instead of `str(...)`.

Acceptance: `fetch_canvas` against a live MCP server returns `source == "mcp"`
with the real jobs, steps, and outcomes.

### Task 2 — Fix tool-error surfacing (Fix B)

**Files:**
- `apps/studio-api/src/agentic_odi_studio_api/studio/mcp_data.py` —
  `call_mcp_tool` returns the extracted text.
- `apps/studio-api/src/agentic_odi_studio_api/studio/chat.py` — the tool
  result fed back to the model uses the extracted text.

Acceptance: a tool call that fails with `Error: ...` no longer appears as a
success.

### Task 3 — Regression tests for the fixes

**File:** `apps/studio-api/tests/test_studio_mcp_data.py`

Add a stub whose `call_tool` returns an object shaped like a real
`CallToolResult` (a `content` list of text blocks), and use it to cover:

- `fetch_canvas` parses jobs, steps, and outcomes from a realistic result.
- `call_mcp_tool` returns the tool's text, not a repr.

Keep the existing plain-`str` stub tests passing.

**File:** `apps/studio-api/tests/test_studio_chat_branches.py` (extend if
needed) — cover the chat tool-result text.

Run: `uv run pytest apps/studio-api` — must pass, and must fail if Task 1 and
Task 2 are reverted.

### Task 4 — Add the Playwright harness

**Files:**
- `apps/studio/playwright.config.ts` (new) — `testDir: "./e2e"`, `baseURL`
  pointing at the sidecar, the `webServer` array, a chromium project, and
  `globalSetup`.
- `apps/studio/e2e/global-setup.ts` (new) — seeds the repository.
- `apps/studio/package.json` — add `@playwright/test` as a dev dependency and
  an `e2e` script.
- `apps/studio/package-lock.json` — regenerated by `npm install`.

Config requirements:

- `webServer[0]`: `uv run python -m agentic_odi_mcp_server`, `port: 8000`.
- `webServer[1]`: `uv run python -m agentic_odi_studio_api.main`,
  `url: http://127.0.0.1:8100/health`.
- The sidecar's environment must set `AGENTIC_ODI_DB` to a temporary file so
  runs are isolated, and `AGENTIC_ODI_DISABLE_SPA` must not be set.
- `use.baseURL` = `http://127.0.0.1:8100`.

### Task 5 — Keep the runners apart

**File:** `apps/studio/vite.config.ts` — scope `test.include` to
`src/**/*.test.{ts,tsx}` so Vitest does not collect Playwright specs.

**File:** `apps/studio/tsconfig.json` — add a `tsconfig.e2e.json` reference.
**File:** `apps/studio/tsconfig.e2e.json` (new) — includes `e2e` and
`playwright.config.ts`, with `types: ["node"]`.

**File:** `apps/studio/.gitignore` — add `playwright-report/` and
`test-results/`.

Acceptance: `npm run typecheck`, `npm run lint`, and `npm test -- --run` all
pass with the E2E specs present.

### Task 6 — Write the E2E specs

**Files:** `apps/studio/e2e/chat.spec.ts`, `capture.spec.ts`,
`landscape.spec.ts`, `workspace.spec.ts`.

Every locator must be role-, label-, or text-based. No `data-testid`.

Shared setup: a helper that navigates with `?flags=firstRunWizard:off` and
seeds `studio.setupDismissed` so the wizard and the setup conversation do not
block the app.

### Task 7 — Wire the CI job

**File:** `.github/workflows/ci.yml`

- Add the `e2e` job, gated on `vars.AGENTIC_ODI_E2E != 'false'` and marked
  `continue-on-error: true`.
- The job installs Node, runs `npm ci`, `npm run build`, and
  `npx playwright install --with-deps chromium`, then `npx playwright test`.
- Add `e2e` to `ci-green`'s `needs`.
- Rewrite the `ci-green` verification so that `skipped` is tolerated **only**
  for `e2e`; every other job must still report `success`.

## Verification commands

```bash
# Python (from the worktree root)
uv run pytest

# Studio units + types + lint (from apps/studio)
npm run typecheck
npm run lint
npm test -- --run

# E2E (from apps/studio)
npm run build
npx playwright test
```

## Risks and mitigations

- **Wizard blocking the app** — disabled via the documented flag query
  parameter.
- **Vitest collecting Playwright specs** — `test.include` scoped to `src`.
- **`ci-green` failing on a skipped optional job** — per-job expectations.
- **Browser install cost in CI** — chromium only, cached by the runner.
