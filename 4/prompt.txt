## Requirements (from the brief)
`connectors/src/connectors/mcp.py` — class `MCPClientConnector(config: ConnectorConfig, sink: IngestSink, client_factory: Callable[[], Client] | None = None)`:
- `kind = "mcp"`, `name` = config.name, `settings` = `config.mcp_settings()`.
- Default `client_factory` = `lambda: Client(self.settings.url)` (HTTP URL transport).
- `async health() -> HealthStatus`: `async with self._client_factory() as client:` → `await client.list_tools()` → `HealthStatus(ok=True, detail=f"{len(tools)} tool(s) available")`; on ANY `Exception` → `HealthStatus(ok=False, detail=str(exc))`. Must return promptly and not raise.
- `async ingest() -> IngestBatch`: `async with ... as client:` → `list_tools`, `list_resources`; build and append a `catalog` `IngestRecord` whose `content` is JSON of `{"tools": [names], "resources": [names]}` and `raw` holds the full names+uris; for each resource `read_resource(res.uri)` produce ONE `resource` record per returned content block using the block's `.text`; for each name in `settings.tools` call `call_tool(name, {})` producing ONE `tool_result` record (concatenated `.text` of content blocks, else `str(result.data)`). Per-item failures must be collected into `batch.errors` (include the item name) WITHOUT aborting the batch. Append the batch to `self.sink` and return it.
- Re-export `MCPClientConnector` from `connectors/__init__.py`.
