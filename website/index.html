Ask for outcomes, not opinions.

Outcome-Driven Innovation asks customers how much each desired outcome matters and how satisfied they are with it today.

The gap between importance and satisfaction is where products win or die.

Agentic ODI stores those outcomes, scores them, and serves them to any agent over MCP.

Opportunity = Importance + max(Importance - Satisfaction, 0)

86% innovation success rate — as reported in ODI literature (Strategyn)

How it works.

  1. Capture — jobs, steps, and desired outcomes with importance/satisfaction scores, via CLI, connectors, or The Living Studio.
  2. Query — agents call MCP tools for job maps and opportunity scores at decision time, local or hosted.
  3. Steer — The Living Studio shows the Opportunity Landscape, Universal Job Map, and Impact Simulation so the team decides from the same picture.

Run it in 60 seconds.

git clone https://github.com/alehar9320/agentic-odi.git
cd agentic-odi
uv sync --all-packages
python scripts/dev.py

Endpoint chips: MCP http://localhost:8000/mcp · Studio http://localhost:8100

MCP client config snippet:

{
  "mcpServers": {
    "agentic-odi": { "url": "http://localhost:8000/mcp" }
  }
}

Hosted credentials come from the maintainers — open an issue. requires a free Prefect account.
