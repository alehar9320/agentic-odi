Four steps, from an empty machine to a running studio with an agent attached to a real MCP server. Nothing here needs an account.

  1. Get the code

    You need Python 3.10 or newer and uv. Clone the workspace and install every package in it.

    git clone https://github.com/alehar9320/agentic-odi.git cd agentic-odi uv sync --all-packages

    Prefer a binary? The installer puts odi, odipm, odi-cli, and agentic-odi on your path for Linux, macOS, and Windows.

  2. Build the studio

    The Living Studio is a React and TypeScript app. Build it once; the server serves the built assets.

    npm --prefix apps/studio run build

  3. Run both services

    One command starts the MCP server and the studio sidecar together.

    python scripts/dev.py
    ServiceURL
    MCP serverhttp://localhost:8000/mcp
    The Living Studiohttp://127.0.0.1:8100

    For hot reload, npm --prefix apps/studio run dev:full starts the MCP server, the sidecar, and Vite together. For the desktop app, use npm --prefix apps/studio run tauri dev.

  4. Point an agent at it

    The server speaks the Model Context Protocol. Any MCP client can reach it.

    { "mcpServers": { "agentic-odi": { "url": "http://localhost:8000/mcp" } } }

    Every tool is listed in the MCP tool reference. The studio itself is optional — the server is the product, and the studio is one client of it.
