The automated release process is broken. A key problem is that we manually have to approve runs everytime a PR is auto-created for a new release. Releases should go out automatically. We should also tie a date to the release version so that it's visible not just by semver, but also by date of creation (possibly datetime, but human-friendly). There are also tests that break that are meant to enforce that versioning is accurately reflected across material. We need to ensure that this is streamlined and simplified. As a maintainer, the release should go out autoamtically when new changes come into origin/main and builds successfully. The release artifacts should then be attached to the release in github, and a user should be able to retrieve these artifacts instantly, and the instructions for how to install them (without dependencies), are directly available, for all the distribution artifacts. Most importantly, for the CLI and Client Studio.
