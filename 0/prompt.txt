The change makes failures first-class:
- `packages/core/src/agentic_odi_core/remote.py` (new): shared `StudioError`, `StudioErrorCode`, `parse_tool_result()`, `tool_result_text()`. The CLI and the sidecar both use it.

- `apps/studio-api/.../studio/mcp_data.py` + `router.py`: MCP tool errors become typed HTTP errors (404/422/502) instead of `200 {"ok": true, "result": "Error: ..."}`; write routes return the object itself, deletes return `{"deleted": id}`.
- `apps/studio-api/.../studio/chat.py` + `observability.py` (new) + `schemas.py`: the chat stream now has exactly one terminal event (`message` or `error`), MCP reachability is probed first, the LLM/MCP client calls are wrapped, and one redacted JSON log line is written per turn.
- `apps/studio/src/...`: typed `StudioApiError`/`asStudioError`, a shared `FailurePanel` component, chat failures kept in the transcript with Retry, connector notices, 30s health polling, canvas as a union (`CanvasState = loading | ready | empty | error`), a `PanelBoundary` that contains a broken lens, and inline form/catalog errors.
