## MANDATORY RULINGS (override the brief)

R1 — `--now` is POSIX-only. `os.execv(paths.current_link() / "odi", [...])` only works where `current` is a symlink. On Windows (or if `current` is not a symlink / marker-file), do NOT exec — print a message like `Update applied; it will take effect on the next run.` and exit 0. Use a platform check (e.g. `os.name == "posix"` / `hasattr(os, "execv")`) and optionally verify `paths.current_link().is_symlink()`.

R2 — Startup notice. Spec requires that when the background auto-update actually installs a newer version, the process prints `Updated to vX.Y.Z — takes effect next run`. In the daemon thread, capture the return value of `update.maybe_auto_update(...)`; if it is a non-None version string, `typer.echo(f"Updated to v{version} — takes effect next run")`, all inside the same try/except that swallows exceptions so it can never raise.
